# 5.2.2. 制动释放开关

制动释放单元的开关布局如图 5.3 所示，各自的使用和操作在表 5-4 中进行了描述。要释放目标轴的制动，首先按下启用按钮，然后在按住启用按钮的同时，同时按下 B1-B8 中的一个按钮。然后，相应的轴将被释放。
